Приватність сайту

Ця сторінка описує інформаційний сайт Lumen за адресою maksim0-debug.github.io/Lumen/. Сайт представляє незалежний застосунок для моніторингу графіків відключень електроенергії у Київській області.

Що збирає цей сайт

На сайті немає облікових записів, форм введення адрес, рекламних трекерів чи сторонніх скриптів аналітики. Код сайту не встановлює cookies та не записує відомості у локальне сховище браузера. Зображення, стилі та скрипти завантажуються з цього ж сайту.

Хостинг

Сайт розміщений на GitHub Pages. GitHub обробляє технічні дані HTTP-запитів, зокрема IP-адреси, для надання й захисту сервісу. Деталі визначені політикою приватності GitHub.

Зовнішні посилання та завантаження

Кнопки завантаження відкривають файли в GitHub Releases. Посилання на GitHub, ДТЕК та інші зовнішні ресурси ведуть на окремі сайти, де діють їхні правила обробки даних. Цей сайт не отримує відомостей про встановлення або використання завантаженого застосунку.

Сайт і застосунок

Наведений опис стосується цього сайту. Сам застосунок має окремі мережеві функції, зокрема отримання графіків, push-сповіщення та підключення власного джерела моніторингу. Їхня робота залежить від платформи й налаштувань користувача. Код та документація застосунку доступні в репозиторії Lumen.

Зворотний зв’язок

Запитання щодо сайту можна залишити в GitHub Issues. Звернення там публічні: не додавайте приватні адреси, ключі доступу, токени чи адреси особистих баз даних.
