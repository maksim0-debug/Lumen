# ⚡ Cloudflare Worker: Lumen Schedule Monitor & FCM Push

Повністю безкоштовний, надійний та автономний Edge-воркер для моніторингу графіків відключень світла (ТТК / ДТЕК) та миттєвої розсилки Push-сповіщень у додаток **Lumen** через **Firebase Cloud Messaging (FCM)**.

---

## 🎯 Як це працює

1. **Cron Trigger**: кожні 5 хвилин Cloudflare автоматично будить воркер (секунда в секунду, без черг).
2. **Парсер**: воркер завантажує сторінку з графіками та витягує актуальні дані для всіх 12 підгруп (`GPV1.1` – `GPV6.2`).
3. **Перевірка відмінностей**: поточний стан порівнюється зі збереженим у **Cloudflare KV** (безкоштовне Key-Value сховище).
4. **Миттєвий Push**: якщо графік певної черги змінився, воркер підписує Google JWT через Web Crypto API та відправляє високорівневий Push-запит у топік цієї черги (наприклад, `group_gpv2_1`).
5. **Доставка**: Google Play Services на телефонах користувачів миттєво показують системне сповіщення, навіть якщо додаток закрито і телефон «спить».

---

## 📋 Покрокова інструкція з налаштування (5 хвилин)

### Крок 1. Завантажити ключ Firebase Service Account
1. Перейдіть у [Firebase Console](https://console.firebase.google.com/) та відкрийте проект **`lumen-power`**.
2. Натисніть на значок шестерні ⚙️ поруч із *Project Overview* -> **Project settings** (Налаштування проекту).
3. Перейдіть на вкладку **Service accounts** (Облікові записи служб).
4. Переконайтеся, що обрано Node.js, і натисніть синю кнопку **Generate new private key** (Створити приватний ключ).
5. Завантажиться JSON-файл (наприклад, `lumen-power-firebase-adminsdk-xxxxx.json`). Збережіть його у надійному місці.

> [!WARNING]
> Ніколи не комітьте цей JSON-файл у Git-репозиторій! Він містить приватний ключ адміністратора.

---

### Крок 2. Авторизація в Cloudflare через термінал
Відкрийте термінал у папці `cloudflare-worker`:

```bash
cd cloudflare-worker
npx wrangler login
```
У браузері відкриється сторінка Cloudflare — натисніть **Allow**, щоб авторизувати CLI.

---

### Крок 3. Створити безкоштовне сховище Cloudflare KV
Виконайте команду:

```bash
npx wrangler kv:namespace create SCHEDULE_KV
```

У консолі з'явиться відповідь схожого вигляду:
```toml
[[kv_namespaces]]
binding = "SCHEDULE_KV"
id = "c3f81e3a98a04b1234567890abcdef12"
```

Відкрийте файл `wrangler.toml` у папці `cloudflare-worker` і замініть значення `id` на ваш новий отриманий ID:
```toml
[[kv_namespaces]]
binding = "SCHEDULE_KV"
id = "c3f81e3a98a04b1234567890abcdef12"
```

---

### Крок 4. Завантажити ключ Firebase у безпечні секрети Cloudflare
Виконайте команду:

```bash
npx wrangler secret put FIREBASE_SERVICE_ACCOUNT
```

Термінал запитає значення:
```
Enter a secret value:
```
Відкрийте завантажений у Кроці 1 JSON-файл у будь-якому текстовому редакторі (Notepad / VS Code), **скопіюйте весь його текст повністю** (від `{` до `}`), вставте в термінал і натисніть **Enter**.

---

### Крок 4.1. Встановити ключ адміністратора (ADMIN_KEY) для захисту ендпоінтів
Щоб сторонні не могли спамити тестовими пушами чи перевантажувати сайт ДТЕК через ваш воркер, встановіть секретний пароль (ключ):

```bash
npx wrangler secret put ADMIN_KEY
```
Введіть будь-який надійний пароль (наприклад: `MySecretKey2026`).

---

### Крок 5. Розгортання (Deploy)
Запустіть деплой:

```bash
npm run deploy
# або: npx wrangler deploy
```

За 3-5 секунд воркер розгорнеться у глобальній хмарі Cloudflare! 
Ви отримаєте публічну адресу вашого воркера, наприклад:
`https://lumen-schedule-monitor.<ваше-ім'я>.workers.dev`

## 🧪 Як протестувати роботу

### 1. Ручна перевірка сайту
Відкрийте в браузері (підставивши ваш `ADMIN_KEY`):
`https://lumen-schedule-monitor.<ваше-ім'я>.workers.dev/check?key=MySecretKey2026`

Воркер миттєво підключиться до сайту ТТК/ДТЕК, перевірить 12 груп і поверне JSON-звіт про стан парсингу.

### 2. Тестовий пуш на телефон
Запустіть додаток **Lumen** на Android-пристрої, оберіть вашу чергу (наприклад, `GPV 2.1`).

**Тестовий пуш на сьогодні:**
`https://lumen-schedule-monitor.<ваше-ім'я>.workers.dev/test-push?group=GPV2.1&key=MySecretKey2026`

**Тестовий пуш на завтра:**
`https://lumen-schedule-monitor.<ваше-ім'я>.workers.dev/test-push?group=GPV2.1&dayType=tomorrow&key=MySecretKey2026`

На ваш телефон миттєво надійде системне Push-повідомлення! ⚡

### 3. Живий моніторинг логів (Live Tail)
Щоб бачити спрацьовування кожні 5 хвилин у реальному часі:
```bash
npx wrangler tail
```
