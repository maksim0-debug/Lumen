# ⚡ Lumen

Сучасний і швидкий додаток для моніторингу графіків та фактичної наявності електроенергії (ДТЕК Київські регіональні електромережі).  
Доступний для **Android** та **Windows**.

## ✨ Основні можливості

### 📊 Графіки та моніторинг
- **Наочний розклад:** Зручне відображення черг відключень на сьогодні та завтра.
- **Таймер перемикань:** Точний зворотний відлік до наступного запланованого ввімкнення або вимкнення.
- **🚨 Екстрені відключення:** Миттєве сповіщення та інформаційний банер у разі запровадження аварійних або екстрених відключень, коли погодинний розклад перестає діяти (з можливістю перегляду офіційного тексту повідомлення ДТЕК).
- **Історія версій:** Фіксація змін графіка протягом дня зі зручним переглядом оновлень.
<img width="360" height="273" alt="Вікно перегляду історії змін графіка відключень ДТЕК" src="https://github.com/user-attachments/assets/507cbab0-0108-49cf-a359-e366717ec4ab" />


### 🔔 Розумні сповіщення
- Завчасті нагадування за **1 годину**, **30 хвилин** або **5 хвилин** до зміни стану.
- Окремі сповіщення про зміну офіційного розкладу ДТЕК.
- Сповіщення про публікацію графіка на наступний день.
- Підтримка моніторингу кількох черг одночасно.
<img width="663" height="626" alt="Екран налаштування розумних сповіщень та вибору черг у Lumen" src="https://github.com/user-attachments/assets/d350b489-5b2a-441b-a9ae-5bc33fe26e27" />


### 🔌 Моніторинг фактичного світла
- **Підключення власного датчика:** Відображення реального стану мережі вдома (через Firebase або локальний сенсор).
- **Захист від хибних статусів:** Розпізнавання втрати зв'язку з датчиком (відсутність інтернету ≠ відключення світла).

### 📈 Аналітика та точність
- **План vs Факт:** Порівняння офіційних графіків із реальними даними для оцінки фактичної точності ДТЕК.
- **Особиста статистика:** Зведення за день, тиждень і місяць, середня тривалість відключень та теплова карта найпроблемніших годин.
- **Вплив на розпорядок:** Підрахунок годин без світла в робочий час та у вечірні години.

### 💻 Зручність на Windows та Android
- **Віджети для Android:** Швидкий перегляд поточної ситуації на головному екрані смартфона.
- **Керування з клавіатури на Windows:** Повна навігація гарячими клавішами (працює на будь-якій мовній розкладці, шпаргалка за клавішею `F1`).
- **Робота в системному треї:** Непомітна фонова робота на ПК без зайвого використання ресурсів.
- **Інтеграція з Розумним будинком:** Вбудований локальний REST API для зв'язку з Home Assistant та іншими системами автоматизації.
- **Персоналізація:** Гнучкі налаштування інтерфейсу та вибір тем оформлення.

## 📥 Завантаження та встановлення

Перейдіть у розділ **[Releases](https://github.com/maksim0-debug/Lumen/releases)** та завантажте останню версію:

- **Android:** завантажте та встановіть файл `.apk`.
- **Windows:** завантажте інсталятор `.exe` (або портативний `.zip` архів).
